# PrepPlace → Branding & Naming Research

> Working name today: **PrepPlace** (deployed as `prepnext.vercel.app`).
> Decision in progress: rename to a more professional, MNC-grade brand for college/campus go-to-market.

## Decision (current): **CareerSphere**

Professional, platform-scale name that reads like an established firm — suitable for walking into colleges to hire interns and place students.

### Domain availability (verified via RDAP, 2026-06-30)
| Domain | Status | Use |
|---|---|---|
| `careersphere.in` | ✅ available | **Primary** (on-brand for India campus) |
| `careersphere.co` | ✅ available | Defensive / redirect |
| `careersphere.com` | ❌ taken | — |
| `careersphere.ai` | ❌ taken | — |

⚠️ Because `.com` and `.ai` are owned by others, **verify before printing**: open both sites to check for an active same-space company, run a trademark search at [ipindia.gov.in](https://ipindia.gov.in) (class 41 education / 35 recruitment), and check LinkedIn/Instagram/X handles.

## Market context for the naming choice
Modern hiring/edtech firms credibly use non-`.com` TLDs — e.g. **Eightfold.ai** (AI recruiting), takeUforward.**org**. A clean coined name on `.in`/`.ai` reads as professional and big-tech; `.com` is not required.
